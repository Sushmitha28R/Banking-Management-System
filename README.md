# Banking Management System 🏦

A Core Java backend application designed to simulate basic banking operations using Object-Oriented Programming (OOP) principles.

## Features ✨
* **Account Creation**: Supports Savings and Current accounts.
* **Transactions**: Secure Deposit and Withdrawal operations with real-time balance validation.
* **Account Status**: View current balances and profile updates.

## Tech Stack 🛠
* **Language**: Java (Core Java)
* **Build Tool**: Maven
* **IDE**: IntelliJ IDEA
